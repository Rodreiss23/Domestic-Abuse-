# Understanding Domestic Abuse – Standalone Website

A calm, clear multi-language guide (English, Hausa, Yorùbá, Igbo) about recognizing domestic abuse.

## What's included

- `index.html` — the complete website (single file + images)
- `images/` — all photos used on the site

## How to use / host it

### Option 1: Just open it
Double-click `index.html` or open it in any browser. It works fully offline.

### Option 2: Free permanent hosting (recommended)

**GitHub Pages (free)**
1. Create a new GitHub repository
2. Upload the entire `domestic-abuse-guide` folder
3. Go to Settings → Pages → Deploy from branch `main` / root
4. Your site will be live at `https://yourusername.github.io/repo-name`

**Cloudflare Pages / Netlify**
- Drag and drop the folder onto their dashboard
- Instant free HTTPS + custom domain support

**Traditional web hosting**
- Upload the folder via FTP/cPanel to your public_html (or similar)

### Option 3: Your own domain
Point your domain’s DNS to whichever host you choose (GitHub Pages, Cloudflare, Netlify, or a VPS).

## Notes
- The site is 100% static — no server, no database, no Vercel needed.
- Google Fonts are still loaded from Google (you can self-host them later if you want zero external requests).
- All images are now local.
